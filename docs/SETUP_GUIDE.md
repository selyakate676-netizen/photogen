# Setup Guide

Этот документ объясняет, как запустить проект локально и проверить, что он работает.

## 1. Установить зависимости

В папке `app` выполните:

```bash
npm install
```

Это скачает библиотеки, которые нужны проекту.

## 2. Подготовить настройки

Скопируйте шаблон:

```bash
copy .env.example .env.local
```

После этого заполните `.env.local` реальными значениями. Реальные значения берутся у владельца проекта или из приватного хранилища паролей.

Не публикуйте `.env.local`.

## 3. Запустить локально

```bash
npm run dev
```

Откройте:

```text
http://localhost:3001
```

## 4. Собрать production build

```bash
npm run build
```

Эта команда проверяет, что проект может собраться для сервера.

## 5. Запустить production build

Сначала выполните:

```bash
npm run build
```

Затем:

```bash
npm run start
```

## 6. Команды проверки

Проверка кода:

```bash
npm run lint
```

Проверка TypeScript на Windows:

```bash
node_modules\.bin\tsc.cmd --noEmit
```

Если PowerShell блокирует `npm`, используйте:

```bash
npm.cmd run dev
npm.cmd run build
npm.cmd run lint
```

## 7. Частые проблемы

- Если не работает вход или загрузка фото, проверьте `.env.local`.
- Если нет доступа к Supabase, проверьте ключи Supabase.
- Если не работает генерация, проверьте `REPLICATE_API_TOKEN`, `WEBHOOK_SECRET` и S3-настройки.
- Если сборка проходит, но функции не работают, скорее всего не заполнены реальные env-переменные.
