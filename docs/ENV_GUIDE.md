# Env Guide

Env-файлы хранят настройки проекта. Некоторые настройки являются секретами: пароли, API keys, Supabase service role key, токены и webhook secrets.

## Какие env-файлы используются

- `.env.local` - реальные значения для локальной машины владельца или сервера. Этот файл нельзя публиковать.
- `.env.example` - безопасный шаблон без реальных значений. Его можно хранить в GitHub.
- `.env`, `.env.production`, `.env.development` - дополнительные локальные env-файлы, если они понадобятся. Они тоже не должны попадать в Git.

## Где хранить реальные значения

Реальные значения должны храниться:

- в `.env.local` внутри проекта на машине владельца;
- в приватном менеджере паролей;
- в настройках сервера или хостинга, если проект развёрнут в production.

Нельзя хранить реальные значения в:

- `README.md`;
- `ROADMAP.md`;
- файлах внутри `docs/`;
- исходном коде в `src/`;
- сообщениях в публичных чатах;
- `.env.example`.

## Обязательные переменные

Эти переменные нужны для основной работы проекта:

- `NEXT_PUBLIC_SUPABASE_URL` - адрес Supabase проекта.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - публичный ключ Supabase для клиента.
- `SUPABASE_SERVICE_ROLE_KEY` - приватный ключ Supabase для серверных webhook-операций.
- `REPLICATE_API_TOKEN` - токен Replicate для AI-обучения и генерации.
- `WEBHOOK_SECRET` - секрет для проверки webhook-запросов.
- `S3_ENDPOINT` - адрес S3-хранилища.
- `S3_REGION` - регион S3.
- `S3_BUCKET_NAME` - имя bucket.
- `S3_ACCESS_KEY` - ключ доступа S3.
- `S3_SECRET_KEY` - секретный ключ S3.
- `NEXT_PUBLIC_SITE_URL` - публичный адрес сайта.

## Опциональные или будущие переменные

- `OPENAI_API_KEY` - ключ OpenAI, если будет добавлена интеграция OpenAI.
- `DATABASE_URL` - строка подключения к базе, если понадобится прямое подключение.
- `NEXT_PUBLIC_VERCEL_URL` - адрес Vercel, если используется Vercel.
- `NEXT_PUBLIC_YANDEX_METRICA_ID` - счётчик Яндекс Метрики.
- `PAYMENT_STORE_ID` - идентификатор платёжного магазина.
- `PAYMENT_SECRET_KEY` - секрет платёжной системы.
- `SUPABASE_DB_PASSWORD` - пароль базы Supabase для ручных операций.
- `VPS_IP`, `VPS_DOMAIN`, `VPS_ROOT_PASSWORD` - данные VPS, если владелец хранит их локально.
- `GITHUB_USERNAME`, `GITHUB_REPO`, `GITHUB_TOKEN`, `GITHUB_PASSWORD` - данные GitHub, если нужны для локального обслуживания.

## Что такое .env.example

`.env.example` - это список имён переменных без реальных значений. Он нужен, чтобы понять, какие настройки надо заполнить в `.env.local`.

Правильно:

```text
NEXT_PUBLIC_SUPABASE_URL=
OPENAI_API_KEY=
```

Неправильно:

```text
OPENAI_API_KEY=real_secret_value
```

## Как восстановить env при переносе проекта

1. Скопировать `.env.example` в `.env.local`.
2. Заполнить `.env.local` реальными значениями из приватного источника.
3. Проверить, что `.env.local` не попадает в Git.
4. Запустить `npm.cmd run build`.

## Правило безопасности

Если секрет случайно попал в код, документацию или GitHub, его нужно считать скомпрометированным и заменить в сервисе, где он был создан.
